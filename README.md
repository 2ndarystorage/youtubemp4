# おうち動画保存 — iPhone単体版

YouTubeの単体動画URLを貼り付けると、iPhone単体でMP4化し、そのまま写真アプリへ保存する個人用アプリです。

- Mac連携（旧Web／サーバー版）は v1.4 で削除しました。Mac・自宅Wi-Fi・接続キー・変換サーバーは不要です。
- 保存先は写真アプリに絞っています。取得が完了すると自動で写真アプリに保存し、中間のMP4は削除します（写真への保存に失敗した場合だけ、「ファイル」アプリの「このiPhone内 → おうち動画保存」に残します）。
- 再生や切り取りは写真アプリで行ってください。

導入手順・使い方・制限は [ios/README.md](ios/README.md) を参照してください。初回ビルドとインストールにはMacのXcodeと自分のApple Accountが必要です（インストール後の利用にMacは不要です）。
